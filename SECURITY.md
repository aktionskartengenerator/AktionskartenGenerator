# Security / Sicherheit

[Deutsch](#deutsch) · [English](#english)

## Deutsch

### Unterstützte Versionen

Korrekturen gibt es nur für die jeweils neueste veröffentlichte Version.

### Sicherheitslücke melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue.

Nutze stattdessen die private Meldefunktion von GitHub: im Repository auf den Reiter „Security“
gehen und dort „Report a vulnerability“ wählen. Die Meldung ist nur für die Betreuer*innen des
Projekts sichtbar.

Hilfreich sind: betroffene Version, Betriebssystem, Schritte zum Nachstellen und die mögliche Auswirkung.

### Was du erwarten kannst

Das Projekt wird in der Freizeit betreut. Eine Rückmeldung kommt so bald wie möglich, eine feste
Frist gibt es nicht. Nach einer Korrektur wird die Lücke in den Hinweisen zur neuen Version genannt.

## English

### Supported versions

Fixes are provided only for the latest released version.

### Reporting a vulnerability

Please do **not** report security vulnerabilities as a public issue.

Use GitHub's private reporting instead: open the “Security” tab of the repository and choose
“Report a vulnerability”. The report is visible only to the maintainers of the project.

Helpful details: affected version, operating system, steps to reproduce and the possible impact.

### What to expect

The project is maintained in spare time. You will get a response as soon as possible; there is no
fixed deadline. After a fix, the vulnerability is mentioned in the notes of the new version.
